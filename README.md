# TripRoute Pro — 自助旅行多天路線規劃(靜態網頁)

純前端、零建置、可直接部署到任何靜態主機(GitHub Pages / Netlify / Cloudflare Pages)。

## 功能總覽

### 行程管理
- **多行程**:建立 / 重新命名 / 複製 / 刪除多個行程,全部存在瀏覽器 localStorage
- **匯出 / 匯入 JSON**:跨裝置備份與還原
- **分享連結**:行程編碼進網址,對方開啟即可一鍵匯入
- 舊版(v1)景點資料會自動遷移

### 景點
- **即時搜尋建議**(需啟用 Places API;未啟用自動退回 Geocoding 搜尋 + 候選清單)
- 地圖上**點兩下**直接加點(自動反查地址)
- **我的位置**一鍵加入
- 每個景點可設定:**停留時間**、**備註**、**所屬天數**
- **拖曳排序**(或上下鍵微調)、刪除可**復原**(6 秒內)

### 路線規劃(多天)
- 每天獨立設定:出發時間、交通方式(開車/步行/自行車/大眾運輸)、起終點、環狀
- **智慧最佳化**:
  - Google 路線:伺服器端 `optimizeWaypoints`(真實道路距離/時間)
  - 超過 25 個 waypoint:本地最近鄰 + 2-opt 排序後**自動分批**請求 Google
  - 大眾運輸:**逐段查詢**並串接出發時刻(Directions 的 TRANSIT 不支援 waypoints)
  - 離線/省額度模式:取消「使用 Google 路線」改用直線估算(速度×繞路係數)
- **依目前順序規劃**:手動排序後直接計算
- **時間表**:依出發時間 + 各點停留時間 + 路段時間,自動算出每點抵達/離開時刻

### 輸出
- **在 Google Maps 開啟導航**(超過 10 點自動分段給連結)
- 每路段「導航此段」連結
- 複製行程文字、**匯出 CSV**(Excel 可開)、**列印 / 存 PDF**

### 其他
- 亮 / 暗主題(地圖同步換色)
- PWA:可「加入主畫面」,斷網時仍可開啟介面(地圖功能需網路)
- 響應式:手機、平板、桌機

## 使用

1. 開啟網頁,貼上 Google Maps API Key(只存在你的瀏覽器 localStorage)
2. 搜尋景點 → 加入;或地圖點兩下加點
3. 用「＋ 加一天」拆多天行程,拖曳調整每天的順序
4. 「✨ 智慧最佳化路線」或「📋 依目前順序規劃」
5. 看時間表 → 開導航 / 匯出 / 列印

## 本機測試

```bash
python -m http.server 8080
```

開啟 http://localhost:8080/
